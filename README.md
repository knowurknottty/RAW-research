# RAW-research

This repository was created by **knowurknot** to hold the results and methodology behind each branch’s title topic. Every branch is a self-contained research package covering a distinct subject — built to adversarial, primary-source standards and documented so that anyone can read, verify, or reproduce the work.

Each branch contains:
- A **CSV data table** with row-by-row findings
- A **whitepaper-format document** for academic or policy audiences
- A **public-facing article** written in Substack style
- A **prompt pack** documenting the exact methodology and user intent, so any reader can confirm the research was not led toward a predetermined answer

## How to navigate GitHub branches

If you want to explore directly in GitHub without using the links above:

1. Click the **branch selector** dropdown near the top-left of the file list (it will say `main` by default).
2. Select the branch name for the topic you want.
3. The file list will update to show that branch’s contents.

---

*New research topics will appear as new branches. Each branch is independent and complete on its own.*
